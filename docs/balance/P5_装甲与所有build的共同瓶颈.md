# P5 结论：装甲线成立（§26-D 是肯定的），但所有 build 卡在同一个瓶颈

2026-08-26。§6.2 的五级装甲树实现完毕，数值逐项对上文档
（3 级装甲 30% 减伤、第 4 张卡晋升尖刺、满级滚筒 45%/60/450/1 格）。

## §26-D「底座近战是否创造新的 Build」：是，而且强得出乎意料

绕开经济、直接摆 build（每组 5 局，`field` 策略）：

| build | 门数 | 名义总 DPS | 平均存活 |
|---|---|---|---|
| 8 门 gun@3（无装甲） | 8 | 1,067 | 84.6s |
| 无炮塔 + 四面满级尖刺 | 0 | 0 | 87.5s |
| 无炮塔 + 四面满级链锯 | 0 | 0 | 235.2s |
| **无炮塔 + 四面满级滚筒** | **0** | **0** | **507.5s** |
| 8 门 gun@3 + 四面满级尖刺 | 8 | 1,067 | 157.2s |
| **8 门 gun@3 + 四面满级滚筒** | 8 | 1,067 | **580.9s** |
| 对照：8 门 Spread Gun@1 | 8 | 448 | 282.3s |

**满级滚筒一门炮塔都不带，活 507 秒，比最好的武器 build 还长 1.8 倍。**

原因和 P6 那条 AoE 结论是同一个：滚筒是"1 格范围内每秒 450 × 四面"的贴身持续 AoE，
而这条敌人曲线后期同屏三四百只，全都往车体上贴——正好撞在它的输出面上。

装甲的前两级（装甲、尖刺）几乎没用（87.5s ≈ 无装甲的 84.6s），
因为它们只有减伤和"每次被打反弹 20-60"，对上百点血的敌人不痛不痒。
**有输出的是链锯起的三级**（光环 75 → 225 → 450 每秒）。

## 但所有路线都卡在同一个地方：经济跟不上

| build | 造价（金币） | 存活 | 每千金币买到的秒数 |
|---|---|---|---|
| 8 门 gun@3 | 2,400 | 84.6s | 35.2 |
| 8 门 Spread Gun@1 | 4,800 | 282.3s | **58.8** |
| 四面满级尖刺 | 3,000 | 87.5s | 29.2 |
| 四面满级链锯 | 12,600 | 235.2s | 18.7 |
| 四面满级滚筒 | 204,600 | 507.5s | 2.5 |

**当前经济产出：约 850 金币 / 70 秒**（P6 实测，玩家死亡时的累计值）。

也就是说：连最便宜的强 build（8 门 Spread Gun，4,800 金币）都要 6 分多钟才攒得出来，
而玩家在 2-3 分钟就死了。**产出和造价差 1-2 个数量级。**

## 这就是当前最该动的那个数

前面几轮测出来的东西现在能串成一条线：

1. 波次曲线推演局长 26.7 分钟，前提是"4 门满级穿刺枪"（83 万金币）；
2. 实际最强的 AI 只活 6.2 分钟，因为 build 长不起来；
3. 补上商店经济之后反而更短（70-190 秒），因为经验升级那套占位系统其实比
   文档的经济**慷慨得多**；
4. 调初始金币（200 → 2000）、商店间隔、商店距离，存活只从 70 涨到 92 秒；
5. 现在看清了：不是经济参数的问题，是**产出量级**的问题。

三条出路，都是设计决定：

- **金币产出提高 5-10 倍**（改 §4.5 的 `coin` 基准或成长系数）；
- **卡价降低 5-10 倍**（改 §8.6 的 100/×5 阶梯）；
- **前 2-3 个周期的敌人曲线大幅放缓**，给成长留出时间。

第三条最可能是对的——现在第 1 个周期（前 80 秒）就要求 400+ DPS，
而开局那 200 金币只买得到 2 门枪（133 DPS）。
