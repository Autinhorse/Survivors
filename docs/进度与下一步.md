## 今天（8/22）做完的

十五个提交，四组事。细节都在提交信息和 `styles/hellrider/README.md` 里。

**一、地面的明暗**（`bdb5e72` `3cd5648`）
格子之上加了一层低频分区。判据是 `tools/hr_ground_stats.py`：只取画面里的
空地，和参考图同口径比。总 std 3.26 → 6.0 左右，落进参考区间 5.5–6.1。
中途把色格转成 45°，**是错的**，已改回轴向 —— 并把"正面 90°、轴向、地面全平"
提升成 README 的**第 4 条不能破的规则**（它原来只写在 `layout.py` 开头）。

**二、面的明暗：三条规则压成一条**（`f3ccc09` `837ad52` `17cfa58`）
亮度只由面法线和光照方向的**夹角 θ** 决定。半 Lambert、档内微分、
`step_weight` 三个补丁全删了 —— 它们都是在补 `dot()` 的毛病。
真正把"暗面不够深"解决掉的是**把四档瞄准相机看得见的那段 θ**（12–105°）：
摊在整个半球上时最暗一档全给了看不见的底面。侧/顶 0.86 → 0.68（参考 0.59/0.72）。

**三、石头的造型**（`80e6b6c` `0226ae4` `7660f2a`）
压掉又深又窄的凹折（`deconcave`）；边数按尺寸分级；第三环只给最大的块；
把法线相近的相邻面并成一个真正的平面（`flatten`）。
最碎的从 404 px²/面 到 919。

**四、大地图**（`da73263` 及其后五个修）
`HellMap.gd` + `ClusterScatter.gd` + `MapInspector.gd`。
**这个模式下没有任何东西是在 Python 里摆死的**，全在运行时生成。

今天真正留下来的其实是**六个判据脚本**：

  按相机参数推导：正交 40° 下是 48.1 m。

**需求文档 §4.1 定的小型敌人：**

    同屏 500–1000（压测 1500–2000+）
    100–300 三角形 / 单位
    3–8 个机械构件（主体 / 腿 / 武器 / 炮塔 / 轮子）
    **避免传统骨骼动画** —— 走程序化 Transform、刚体构件、Shader 动画
    最终形态是 Data-Oriented + MultiMesh，不是 1000 个完整 SceneTree

**风格上不能破的（都在 `styles/hellrider/README.md`）：**

- 单位也是**纯色块**：没有贴图、没有法线扰动，明暗必须分档
- 轴向、地面全平
- 影子走 blob 贴片，不用真实投影。**`blob_scale` 有算得出来的下限**：
  blob 是边长 `blob_scale × 缩放` 的方片，半宽 = `blob_scale/2`；
  物体半宽超过它，整片影子就藏在物体底下 —— 今天这个坑复发了三次

**参考图里的角色**：`styles/hellrider/reference/` 里的骷髅兵和摩托车手 ——
骷髅约 1.8 m，是全套尺度的锚。我们的方块是 1.6 m。

## 今天走过但否决的路

- **色格转 45°**。理由当时是"熔岩外侧那层装饰菱形本来就是 45°"。是错的：
  参考图的菱形是**等距投影**的产物，照抄角度等于照抄了一台我们没有的相机。
  同一个陷阱今天还在余烬上重犯了一次（随机 yaw 的斜方块）。
- **生成场景时按最终 yaw 烘方向性明暗**。前提是成立的（道具摆下去就不动），
  但量过之后不值：邻面跳变只影响 1.6% 的边，而代价是散布物的 MultiMesh
  合批全没了。数字在 README 的「已知待办」里。

## 存着的一条岔路：换造型语言

`docs/造型语言试验.md` —— 2026-08-22 试过"大小不一的方块 + 边角加亮"那套
（RTS 常见的语言）。**在 90° 正视下成立**，前提是墙面朝向要散开：
树靠转朝向（yaw 20–70°），山靠**平面轮廓带 30/45/60° 斜边**（墙仍垂直）。

不倒角只要 42–100 tris（现在的平滑低模是 ~30），而生成代码简单得多 ——
`deconcave` / `flatten` / 面数分级 / 底面椭圆这些今天花时间最多的东西
在那套语言里根本不存在。而且我们的地面本来就是方格、熔岩是方块，其实更搭。

代码在 `styles/hellrider/experiments/`，图在 `docs/reference/斜边台地_*.png`。
**先不采纳**：换语言等于不再跟 Hellrider 参考图，实测校准要重推一遍。
